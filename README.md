# PSOC™ Edge E3 Training - Extended Boot

This training is part of the PSOC™ Edge Security training series and focuses on
Extended Boot and its key features in PSOC™ Edge devices.
This session covers the basics of Extended Boot, including its role in the
hardware Root of Trust and involves the verification and launch of RRAM_SE_BOOT
and Extended Boot stored in the device's RRAM.
Additionally, this training covers the Secure Boot option, and the support provided
by Edge Protect Tools for provisioning PSOC™ Edge devices.

## Device family
- [PSOC™ Edge](https://www.infineon.com/products/microcontroller/32-bit-psoc-arm-cortex/32-bit-psoc-edge-arm)
